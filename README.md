# Tunalı drone kör testi

Emlak ilanları için yapay zekâ ile üretilen drone tarzı videoların kör değerlendirme sayfası.
Videolar aynı fotoğraftan farklı yöntemlerle üretildi; hangi videonun hangi yöntem olduğu bu depoda yok.

Kaynak fotoğraf: Kayra, [Tunalı Hilmi Caddesi 2025](https://commons.wikimedia.org/wiki/File:Tunal%C4%B1_Hilmi_Caddesi_2025.jpg), Wikimedia Commons, CC BY 4.0.
Kişiler ve plakalar gizlilik için kaldırıldı. Videolar bu fotoğraftan türetilmiştir ve yapay zekâ ile üretilmiştir.
